# Local font licenses

TAKATAK serves its existing Geist, Geist Mono, Inter, Montserrat and Instrument Serif font families from local, Next.js-generated static assets. The original license text for each family is reproduced beside this file. The source is the corresponding `@fontsource-variable/*` or `@fontsource/instrument-serif` npm package, pinned to version 5.3.0 in `package-lock.json` with npm integrity metadata. No font is fetched from Google at build or page-render time.
